## When to reach for GLM-5.3

GLM-5.3 (August 14, 2026) is Z.ai's current flagship and the strongest model the
GLM line has shipped. It reuses the same ~743B mixture-of-experts base as
GLM-5.2 (~40B active per token) — the gains come from extended post-training on
agentic coding and security work rather than a new pretrain.

- Long-horizon coding agents: it posts the highest Terminal-Bench 2.1 score of
  any GLM release, and Z.ai claims roughly a 50% coding gain over 5.2.
- Vulnerability research — Z.ai's own post-training run turned up 1,097 critical
  bugs and produced exploit chains the team had not designed for.
- 1M-token context, same as 5.2.

> **Weights shipped August 28 — but not under MIT.** GLM-5.3 launched
> Coding-Plan-only on August 14; Z.ai held the ~753B checkpoint for a safety
> review and published it on Hugging Face two weeks later. Despite earlier
> signals, it uses a **bespoke `glm-5.3` licence**: MIT-style permissions, with
> one condition — Model-as-a-Service operators above **$10B in trailing
> 12-month revenue** must pass a Z.ai security review before commercial use.
> For most teams that changes nothing. If you need a plain MIT GLM, use
> **[GLM-5.2](/models/zhipu-glm-5-2)** or
> **[GLM-5.3-Flash](/models/zhipu-glm-5-3-flash)**.

## Specs & cost

- **Architecture:** ~743B total parameters, MoE, ~40B active per token.
- **Context:** 1M tokens.
- **Pricing:** no per-token rate card. Access is bundled into the GLM Coding
  Plan subscription, so it is deliberately **not** listed in this catalog's
  price comparison.
- **Licence:** bespoke `glm-5.3` licence (MIT-style, plus a security-review
  condition for MaaS operators above $10B revenue). Weights on Hugging Face
  since August 28, 2026.

## Benchmark notes

Terminal-Bench 2.1 (88.2) is recorded. Two caveats worth carrying:

- The figure is **Z.ai-run**, not independently reproduced, and the URL cited is
  a third-party relay of Z.ai's numbers rather than z.ai's own docs page.
- Z.ai also published **Terminal-Bench 3.0 (28.3)** and **CyberGym (84.5)**.
  Terminal-Bench 3.0 is a different, much harder benchmark — the two scores are
  not comparable to each other, and 3.0 is not part of this catalog's tracked
  set, so neither is recorded as an entry.
