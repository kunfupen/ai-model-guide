## When to reach for Muse Spark Open

Muse Spark Open (October 15, 2026) is Meta's open-weights release of its Muse
Spark line — an **816B-parameter mixture-of-experts model with 42B active**,
which Meta calls the most capable US open-weight model to date. Artificial
Analysis agrees: at 39 on its Intelligence Index it is the top-scoring US
open-weights model.

- Self-hosting a large, natively multimodal coding and agent model.
- Long-horizon software engineering and multi-step reasoning, which Meta
  positions it for.
- A big step up from [Muse Glimmer](/models/meta-muse-glimmer), Meta's 30B
  open-weight model, which scores 17 on the same index.

It is not the same as Meta's API flagship,
[Muse Spark 1.3](/models/meta-muse-spark-1-3), which stays closed.

## Read the licence

The weights ship under the **Muse Model License** — open-weight, not open
source. Two conditions stand out:

- Products built on it must prominently display **"Built with Muse Spark Open"**
  in their interface.
- Above a revenue threshold (reported as $20M in any 12 months) you need a
  separate agreement with Meta, and API resellers face their own terms.

## Specs & cost

- **Architecture:** sparse MoE, 816B total / 42B active parameters.
- **Context:** 1M tokens.
- **Inputs:** text, image, video and audio.
- **Weights:** BF16 and NVFP4 on Hugging Face, Amazon SageMaker AI, Google Cloud
  Model Garden and Microsoft Foundry. Expect roughly 700GB+ of memory even for
  NVFP4.
- **Pricing:** no first-party API price. Hosted access is through Baseten,
  Fireworks AI, Groq, Modal, Nebius, OpenRouter and Together AI, each at its own
  rate.

## Benchmark notes

**No benchmarks are recorded.** Meta's own results have not been independently
checked, and its Artificial Analysis score (39) is outside the tracked set.
