## When to reach for Kimi K3

Kimi K3 (July 16, 2026; weights released July 27) is Moonshot AI's frontier model
and — at **2.8 trillion parameters** — the largest open-weight model shipped to
date. It is a mixture-of-experts design activating only 16 of 896 experts per
forward pass, which is how a model this size stays priced like a mid-tier one.

- Frontier-class reasoning and coding you can actually self-host, with an
  always-on "thinking mode".
- Long-context multimodal work: 1M tokens with native visual understanding.
- Independent testing places it fourth among all frontier models — behind Claude
  Fable 5 and GPT-5.6 Sol, ahead of Claude Opus 4.8 — and it **beats Fable 5
  outright on the Frontend Code Arena** leaderboard (1,679 Elo).

## Specs & cost

- **Architecture:** 2.8T total parameters, MoE, 16/896 experts active per token.
- **Context:** 1M tokens.
- **Pricing:** $3 / 1M input and $15 / 1M output — with cache hits at $0.30 / 1M.
- **Availability:** Moonshot's API, plus downloadable weights (self-hostable via
  vLLM with Kimi Delta Attention support).

## Benchmark notes

Terminal-Bench 2.1 (88.3) and GPQA Diamond (93.5) are both **vendor-reported**,
taken from Moonshot's official README. Terminal-Bench was measured with
Moonshot's KimiCode harness at max reasoning effort, so it reflects the model's
best configuration rather than its default — worth remembering when comparing
against rows here measured on other harnesses.

**No SWE-bench score is recorded, and that is deliberate.** Moonshot's README
does not report SWE-bench Verified or SWE-bench Pro for K3 at all. Third-party
blogs quoting "93.4% SWE-bench Verified" or "76.8% SWE-bench Verified" for K3
are unreliable — the 76.8 figure is actually
**[Kimi K2.5's](/models/moonshot-kimi-k2-5)** number.

Moonshot's README additionally reports BrowseComp (91.2), OSWorld-Verified
(84.8) and DeepSWE (67.5). Those, along with the Artificial Analysis
Intelligence Index score (57 vs Fable 5's 60) and the Frontend Code Arena Elo
cited above, are **not** in this catalog's tracked benchmark set, so they are
not recorded as entries.
