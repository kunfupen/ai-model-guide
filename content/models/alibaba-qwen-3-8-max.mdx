## When to reach for Qwen3.8-Max

Qwen3.8-Max (August 3, 2026) is the largest model Alibaba has shipped and the most
capable in the Qwen family — a **2.4-trillion-parameter mixture-of-experts** model
that activates only ~95B parameters per token, which is how it reaches frontier
scores at $2/$6.

- Frontier-adjacent reasoning and agentic coding at a fraction of Western flagship
  pricing — it undercuts GPT-5.6 Sol ($5/$30) and Claude Opus 5 ($5/$25) several-fold.
- Long-context multimodal work: 1M tokens, with text, image and video input.
- It became the highest-ranked Chinese model for text on Arena.AI, though it still
  trails several Anthropic models including Claude Fable 5.

## Specs & cost

- **Architecture:** 2.4T total parameters, MoE, ~95B active per token.
- **Context:** 1M tokens.
- **Pricing:** $2 / 1M input and $6 / 1M output.
- **Availability:** Alibaba Cloud Model Studio. **Open weights were announced as
  following later** — this page will move to `open-weights` when they land.

## Benchmark notes

⚠️ **These are vendor-run figures.** GPQA Diamond (92.6) and Terminal-Bench 2.1
(86.6) come from Alibaba's own published results, and the coding rows were run
using Anthropic's Claude Code harness rather than a neutral one. They have not
been independently reproduced on the leaderboards used elsewhere in this catalog,
so treat them as the model's best case rather than a like-for-like comparison.

**SWE-bench Verified is omitted.** Alibaba published SWE-bench **Pro** (67.7),
which is a different, harder benchmark and is not interchangeable with the
Verified scores recorded for other models here.
