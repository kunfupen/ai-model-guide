## When to reach for Claude Sonnet 5.5

Claude Sonnet 5.5 (September 28, 2026) is Anthropic's mid-tier model — "the
best combination of speed and intelligence" — and the direct replacement for
[Claude Sonnet 5](/models/anthropic-claude-sonnet-5), which is now legacy.

- High-volume production work where Opus-class reasoning is more than you need.
- Agentic coding: Anthropic reports **70.6 on Terminal-Bench 4.0**, and on an
  independent run it essentially ties Opus 5.5 — at half the price, and a fifth of
  [Fable 5.1](/models/anthropic-claude-fable-5-1)'s price.
- Anything currently on Sonnet 5: the price is identical, so the upgrade costs
  nothing per token.

For the hardest work, [Claude Opus 5.5](/models/anthropic-claude-opus-5-5) is
Anthropic's recommended default at $4/$20.

## Before you migrate

**Same price, but not a drop-in swap.** Anthropic lists five breaking changes
from Sonnet 5:

- **`thinking: {"type": "disabled"}` now returns 400.** To turn off up-front
  thinking, send `{"type": "between_tools"}` instead — accepted at `low`,
  `medium` and `high` effort, rejected at `xhigh` and `max`.
- **Forced tool use is gone.** `tool_choice` of `any` or `tool` returns 400;
  use `auto` with strict tool use.
- **Thinking blocks are bound to the conversation.** For accounts created on or
  after August 31, 2026, replaying a thinking block after editing earlier
  history (system prompt, tools or messages) returns 400. Keep conversations
  append-only.
- **Computer use** needs `computer_toolset_20260801` on the Claude API and
  Google Cloud; the older `computer_20251124` is rejected there.
- **The advisor tool** rejects Opus 4.8, Opus 4.7 and Sonnet 5 as advisors.

One silent change catches streaming UIs: notes longer than a sentence or two
**between tool calls now arrive as `thinking` blocks**, empty by default — so an
app that streams them to users goes quiet with no error until it sets a
`display` value.

Anthropic also says **effort levels are recalibrated** — the same level no
longer produces the same amount of thinking as on Sonnet 5, so re-run your
effort sweep rather than carrying a setting over.

## Specs & cost

- **Model ID:** `claude-sonnet-5-5` (`anthropic.claude-sonnet-5-5` on Bedrock).
- **Context:** 1M tokens, up to 128K output.
- **Thinking:** adaptive, on by default. Default effort `high`.
- **Knowledge cutoff:** June 2026.
- **Pricing:** $2 / 1M input, $10 / 1M output — identical to Sonnet 5,
  including caching and batch rates. Minimum cacheable prompt drops to 512
  tokens, from 1,024.
- **Retirement:** not sooner than September 28, 2027.

## Benchmark notes

**Terminal-Bench 4.0 (70.6)** is from Anthropic's launch announcement — up from
Sonnet 5's 10.3. It puts Sonnet 5.5 at the top of this catalog's Terminal-Bench
4.0 column, **above [Opus 5.5](/models/anthropic-claude-opus-5-5) (66.4)**.

Read that lead with care. On **Vals AI's independent run** the two are
effectively tied, with Opus slightly ahead: **Opus 5.5 65.15, Sonnet 5.5 64.14**.
Both vendor figures are Anthropic's own, and Anthropic's Opus results are
reported at the highest effort setting. What the independent number does show
is that Sonnet 5.5 delivers Opus-class terminal-agent results at **half the
price** — which makes it the better-value choice for most agentic coding.

Anthropic's docs pages ("what's new" and the release notes) list no
benchmarks; the figure is only in the announcement.
