## When to reach for Muse Ember 1.0

Muse Ember 1.0 (November 9, 2026) is the smallest model in Meta's Muse family,
built for high-volume agent work: tool calls, coding subtasks, routing,
extraction and long-document parsing. Meta says it is the first model trained
with Muse Wonder Full, its largest model.

- The cheap, fast step in an agent pipeline. At **$0.10 / $0.50 per 1M** it
  matches [Claude Haiku 5.5](/models/anthropic-claude-haiku-5-5) and
  [GPT-6 Luna](/models/openai-gpt-6-luna) on headline price.
- It scores the same as Haiku 5.5 on the Artificial Analysis Intelligence Index
  (36), at an estimated $0.14 per task against Haiku's $0.41.
- Long inputs on a budget: a 1M-token context, with up to 512K output tokens.

## Specs & cost

- **Model ID:** `muse-ember-1.0`.
- **Context:** 1,048,576 tokens in, 524,288 out.
- **Inputs:** text and image, with text output, per Google Cloud's listing.
  Meta's own messaging also mentions audio and video input, which isn't
  confirmed in the platform listings.
- **Pricing:** $0.10 / 1M input, $0.50 / 1M output; a cached-input rate of about
  $0.004 / 1M is reported.
- **Availability:** the Meta Model API and Muse Code, Google Cloud, and Oracle
  Cloud. **No open weights**, and no parameter count is disclosed.

It is a different model from [Muse Glimmer](/models/meta-muse-glimmer), Meta's
small *open-weight* model, and doesn't replace it.
