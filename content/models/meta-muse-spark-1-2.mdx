## When to reach for Muse Spark 1.2

Muse Spark 1.2 (August 5, 2026) is **Meta's current flagship** — the model that
replaced the Llama line, shipped alongside the Muse Code terminal coding agent.
It is a fully multimodal 1M-context model priced well below the frontier tier.

- Large-codebase agentic work, which is what Muse Code was built around.
- Genuinely wide input: text, image, video, audio and PDF all go in natively.
- Cost-sensitive frontier work — $1.25/$4.25 per 1M undercuts every US flagship
  in this catalog.

> Muse Code is a **CLI product, not a model**, so it is not listed separately
> here. It runs on Muse Spark 1.2.

## Specs & cost

- **Context:** 1,048,576 tokens.
- **Pricing:** $1.25 / 1M input, $4.25 / 1M output, $0.15 / 1M cached input, on
  the standard Meta Model API tier. A cheaper **Contributor** tier
  ($0.10/$0.20) trades data-usage rights for price — that is a pricing tier on
  the same model, not a separate model.
- **Licence:** proprietary. Alexandr Wang announced an intent to release open
  weights on August 10, 2026, but nothing had shipped as of August 18, so this
  is recorded as API-only.
